Rules that apply to every lane call:

- **One packet, one worktree.** `git worktree add C:/Code-worktrees/llm-relay/pkt-<id> -b pkt/<id> <lap branch>`,
  `node_modules` wired as a junction to `C:\Code\llm-relay\node_modules`. Two lanes never share a tree.
- **The lane never commits.** Its last step writes `git diff --binary HEAD > <scratch>/pkt-<id>.patch`.
  This session applies the patch in the lap worktree, runs `llm-relay delegate-gate`, typechecks,
  runs the packet's tests, reads the diff, deletes the backlog entry, and commits.
- **The brief lives in a file**; the task text points at it. Every brief states: the files it may
  touch, the property from the backlog verbatim, the test that must go red without the fix, "run
  `npm run typecheck && npm run typecheck:test` and the named vitest files before you finish",
  "write files early", "do not edit `CLAUDE.md`, `HANDOFF.md` or `docs/backlog.md`" (this session
  owns those).
- **MCP `waitMs` stays at 20 000 ms.** Above ~45 s the host drops the job handle (machine backlog).
- **Codex lanes run as background Bash jobs**, so their exit re-invokes this session; no polling.
- **Verification is never a lane's word.** A free lane drops a brief's finest constraint (measured
  2026-09-08/09), so every packet is typechecked and run here before it is believed.
